# Hidden Lake Games — Data & Analytics

Internal repositories for end-to-end game analytics infrastructure.

## Scope

- Game data pipelines (ETL/ELT)
- Player behavior analytics
- Revenue & monetization metrics
- Dashboards and reporting

## Stack

- **SQL** — PostgreSQL, ClickHouse, BigQuery
- **Python** — pandas, Airflow, dbt
- **Cloud** — AWS / Azure / GCP
- **BI** — Looker, Tableau, Superset
